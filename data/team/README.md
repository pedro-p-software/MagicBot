# Team knowledge documents

Arquivos nessa pasta são a fonte do bot. Os mantenha curtos condizentes e atualizados. O indice de busca rebuilda automaticamente se mudar alguma coisa

Nao adicione informações pessoais, (caixa, senhas, assuntos delicados) o bot terá acesso a eles e poderá citá-los em qualquer lugar

Os 3 arquivos abaixo desse são a fonte dos comandos `/agenda`, `/links`, and `/onboarding`.
